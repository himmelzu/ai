제안명: AI 개발 보조로 구현하는 PDF 기반 여비명세서 자동화

소속: __________　성명: __________　직급: __________

1. 개선이 필요한 업무 및 문제점

출장처리 시스템에 이미 입력된 내역을 여비지급명세서로 작성할 때, 담당자는 날짜·시간·출장지·목적을 다시 옮기고 차량 사용 여부에 따른 일비와 합계를 계산한다. 같은 정보를 다른 서식으로 옮기는 과정에서 반복 입력과 대조 작업이 발생한다.

개인별 출장내역 PDF에는 신청행과 확인행이 함께 표시되어 예정시간과 실제시간을 혼동하기 쉽다. 한 출장의 두 행이 페이지 사이에서 나뉘기도 하며, 미전송 등 청구에 포함하지 않을 내역도 구분해야 한다. 기존 시스템에서 내려받은 PDF를 바로 업무 양식으로 바꾸는 도구를 제안한다.

2. AI 활용 아이디어

AI 개발 도우미로 업무 규칙과 변환 도구를 구현하고, 직원은 PDF 선택 → 내역 확인·필요 수정 → 명세서 저장으로 사용한다.

AI 개발 보조를 활용하여 PDF 표 구조 분석, 실제·신청시간 구분 규칙, 계산 코드, 서식 생성과 검증 사례를 구현한다. 현재 프로그램의 실행 단계는 PDF 안의 문자·표를 직접 추출하고 정해진 계산 규칙을 적용하는 방식이다. 이미지 문자 인식이나 생성형 AI가 출장 내역을 판단하는 기능으로 설명하지 않는다.

업무에 맞춘 핵심 설계는 다음과 같다.

• 실제 시간 우선: 신청·확인행을 출장별로 묶고 확인행의 실제 일시를 사용한다. 실제 시간이 없으면 신청시간으로 대신 채우지 않는다.
• 상태·대상 구분: 개인별 PDF의 확인행에 표시된 상태를 우선하며 미전송 등은 기본 제외한다. 관외·여러 날 출장은 관내 예시 기준의 자동 계산 대상에서 제외한다.
• 간단한 서식화: PDF를 넣으면 내역과 금액이 자동으로 준비된다. 수정은 화면에서 하고, 출력에는 검토 상태 워터마크를 넣지 않는다. 서명·날인은 자동 생성하지 않는다.
• PC 내부 처리: 원본 PDF와 출장 내역을 외부 서버로 보내지 않는다. AI 개발 보조의 역할과 실행 프로그램의 처리 방식을 구분한다.

초기 구현은 개인별 출장내역과 기존 월별집계 텍스트 PDF를 읽고, 편집 화면·관내 일비 계산·A4 가로형 여비지급명세서 출력을 제공한다. 기준시간·일비·차량 차감액·동일인 동일일 상한은 기관 기준에 맞게 조정할 수 있다. 초기값인 4시간 이상 2만원, 미만 1만원, 차량 사용 시 1만원 차감, 일일 상한 2만원은 예시이며 기관의 현행 기준을 확인하여 적용한다.

3. 업무 처리 방식 비교

[업무 처리 방식 비교]
처리 절차
현재(As-Is): 출장내역 확인 → 명세서에 재입력 → 실제시간·차량·대상 대조 → 계산·서식 정리
개선 후(To-Be): 개인별 PDF 선택 → 자동 추출·계산 → 필요 항목 수정 → 명세서 PDF 저장

소요 시간
현재(As-Is): 반복 전사와 양식 정리에 시간이 듦. 현재 시간은 실측 필요
개선 후(To-Be): 전사·합계·서식 작업을 줄이는 것이 목표. 절감 시간은 아직 실측하지 않음

오류·인력
현재(As-Is): 신청·실제시간 혼동, 누락, 합계 오류 등을 담당자가 확인
개선 후(To-Be): 확인행 우선 처리와 고정 계산 규칙으로 대조를 지원하며, 원본과 결과 확인은 담당자가 수행

자료 처리
현재(As-Is): 담당자가 원본과 작성 파일을 관리
개선 후(To-Be): 원본 추출·계산·서식 생성을 PC 내부에서 처리하고 출력 PDF는 담당자가 관리


효과는 같은 가명 출장 10건으로 수기 작성과 도구 사용을 각각 수행하여 검증할 계획이다. PDF 불러오기부터 수정·원본 대조·저장까지의 총시간, 실제 일시·차량·금액의 원본 일치 여부, 수정 건수를 비교한다. 측정하지 않은 절감률이나 정확도를 실적으로 제시하지 않는다.

4. 기대효과

이미 입력한 출장 정보를 다시 옮기는 작업을 줄이고, 담당자가 실제시간·차량·청구대상과 금액 확인에 집중하도록 돕는다. 정해진 기관 서식을 자동으로 구성하여 문서 정리에 드는 수작업도 줄이는 효과를 기대한다.

AI 개발 보조를 활용해 현업의 반복 작업을 작은 PC용 도구로 구체화한 사례로 확장할 수 있다. 같은 시스템·양식을 사용하는 부서부터 가명 자료로 시험하고, 다른 PDF 양식과 지급기준은 별도 검증 후 적용한다. 현재 구현은 문서 전사·계산·서식화를 돕는 도구이며 지급 적정성이나 결재를 대신 판단하지 않는다.

실제 Windows PC의 사용 흐름과 담당자 시범 사용을 추가 확인하고, 기관의 프로그램 사용 절차·지급기준·출력 양식에 맞춰 업무에 적용한다.
