# 여비청구서 변환기 사용설명서

출장처리 목록 캡처를 기본으로 읽고, 필요하면 월별집계 PDF도 불러와 내용을 확인·수정한 뒤 **A4 가로형 여비지급명세서 PDF**로 저장하는 초기 버전입니다. 신청서나 결재를 대신 제출하는 프로그램은 아닙니다.

## 준비

- Windows 10/11 64비트 PC와 기본 웹브라우저를 사용합니다.
- `여비청구서변환기.exe`에 실행 환경과 OCR 구성요소가 포함되어 있어 Python을 별도로 설치하지 않습니다.
- 프로그램의 이미지 인식과 PDF 생성에는 인터넷 연결을 사용하지 않습니다. 실행하면 이 PC에서만 접속하는 브라우저 화면이 열립니다.
- 처음 실행할 때 필요한 구성요소를 사용자 로컬 캐시의 `TravelClaim` 폴더에 풀기 때문에, 화면이 열릴 때까지 잠시 기다려 주세요. 이후 실행에서는 해당 파일을 재사용합니다.

기본 입력은 **근무지내출장처리 목록 표의 캡처**입니다. PNG·JPG·WebP·BMP 파일을 한 번에 하나씩, 최대 20MB까지 넣을 수 있습니다. 18열 출장 월별집계의 텍스트 PDF도 보조 입력으로 선택할 수 있습니다. 글자가 아주 작은 월별집계 화면 캡처는 현재 안정적으로 검증되지 않았으므로 이 경우에는 원본 PDF를 사용하세요. 모든 사진·문서·출장 시스템을 인식하는 범용 OCR 프로그램은 아닙니다.

캡처에는 부서, 직급, 출장자, 실제 출발·복귀 시각, 신청 출장기간, 출장지, 출장목적, 공용차량 여부, 결재상태의 열 제목과 표 테두리가 보이도록 합니다. 작은 글씨, 흐린 촬영본, 기울어진 화면, 잘린 열은 오인식이나 인식 실패의 원인이 됩니다. 가능하면 사진 촬영보다 화면 캡처를 사용하세요.

## 사용 순서

1. `여비청구서변환기.exe`를 실행합니다.
2. 열린 화면에서 캡처를 **Ctrl+V로 붙여넣거나**, 이미지 파일을 선택하거나, 입력 영역에 끌어놓습니다. 월별집계 PDF가 있으면 같은 파일 선택 버튼으로 불러올 수 있습니다. 인식 중에는 완료될 때까지 기다립니다.
3. **원본 캡처 확인**을 펼쳐 표와 인식 결과를 대조합니다. 부서·직급·성명·날짜·실제 출발/복귀 시각·공용차량·출장지·목적·결재상태를 확인하고 잘못 인식한 값을 수정합니다.
4. 청구할 대상만 **포함**으로 선택합니다. 미신청·취소·반려 등으로 인식된 내역은 기본 제외되며, 상태가 불명확한 행은 원본 및 지급대상 여부를 확인합니다.
5. 아래 예시 지급기준을 소속 기관의 현행 기준과 대조합니다. 필요하면 값을 수정하고 **일비 다시 계산**을 누릅니다. 시간·차량·포함 대상 등을 수정한 뒤에도 다시 계산하세요.
6. 계산한 금액과 경비를 확인합니다. 식비·숙박비·교통비·기타 금액을 입력한 경우 일비와 함께 합계·청구액도 확인합니다. 관외 출장이나 여러 날 출장은 이 예시 관내 기준으로 자동 계산하지 않습니다.
7. 지급기준 및 OCR 내용·지급대상 확인을 각각 마쳤을 때 해당 확인란을 직접 표시합니다. 대조 확인자 직급·성명은 필요한 경우 입력합니다.
8. **명세서 PDF 저장** 또는 **검토용 PDF 저장**을 눌러 브라우저가 내려받은 PDF를 확인합니다. 최종 제출 전 원본, 금액, 지급대상, 기관 양식을 다시 대조하세요.
9. 작업이 끝나면 화면 오른쪽 위 **종료**를 누른 뒤 브라우저 탭을 닫습니다. 탭만 닫으면 프로그램이 계속 실행될 수 있습니다.

## v0.2.0에서 바뀐 점

- 열 제목 일부가 흐리거나 잘린 캡처도 표선과 본문의 날짜·실제시각·번호를 함께 확인해 열 배치 복구를 시도합니다. 복구 경고가 나오면 값이 올바른 열에 들어갔는지 원본과 대조하세요. 배치가 모호하면 자동 선택하지 않습니다.
- 인식이 실패해도 원본 파일명과 미리보기가 남고 다시 인식할 수 있습니다. 이전 자료가 있으면 그대로 보존하며 새 자료의 결과가 아님을 표시합니다.
- 18열 출장 월별집계 PDF를 보조 입력으로 지원합니다. 실제 시작·종료 일시가 있는 해당 표를 읽으며 암호가 걸린 파일이나 다른 형식의 PDF를 일반적으로 읽는 기능은 아닙니다.

PDF 권한이 없는 경우에는 캡처를 계속 사용하면 됩니다. PDF에는 결재상태가 없으므로 결재완료로 자동 채우지 않습니다. 실제 지급대상임을 확인하고 상태를 입력해야 최종본 조건을 충족합니다. 관외·여러 날 출장은 자동 계산 범위 밖이므로 기본 제외 상태로 표시되며, 필요한 경우 검토 후 포함할 수 있습니다.

월별집계의 교통비와 현지교통비는 출력 교통비에 합산합니다. 일비·청구액은 인식 후 화면의 지급기준에 따라 다시 계산하므로 원본 금액과 다를 수 있습니다. 원본 경비와 적용 기준을 대조하세요. 월별집계에서 읽지 못한 경비 금액은 0원으로 채우지 않고 미확인 상태로 둡니다.

기존 프로그램은 먼저 **종료**한 다음 새 ZIP을 별도 폴더에 풀어 새 EXE를 실행하세요. 화면의 버전 표시가 `v0.2.0`인지 확인합니다. 기존 브라우저 탭만 새로고침하면 이전 실행파일에 연결될 수 있습니다.

## 실제 출장시간과 신청시간

일비 제안 계산에는 **실제 출발·복귀 시각**을 사용합니다. 신청기간의 예정 시각을 실제 출장 시각으로 대신 채우지 않습니다. 실제 시각이 비어 있거나 인식되지 않았다면 확인 후 직접 입력해야 합니다.

신청기간에서 읽은 날짜와 실제 시각을 조합한 결과도 반드시 원본과 확인하세요. 날짜가 바뀌는 출장, 실제 근무기록과 신청기간이 다른 경우 등은 담당자 검토가 필요합니다.

## 기본 지급기준은 예시입니다

| 항목 | 초기 제안값 |
| --- | ---: |
| 기준시간 | 240분(4시간) |
| 기준시간 이상 일비 | 20,000원 |
| 기준시간 미만 일비 | 10,000원 |
| 공용차량 사용 시 차감 | 10,000원 |
| 같은 직원·같은 날 일비 상한 | 20,000원 |

이 값은 기관별 규정, 감액 조건, 지급 제외 사유를 모두 판정하는 법령 검증 기능이 아닙니다. **기관 기준에 맞는지 담당자가 확인한 뒤 사용**해야 합니다. 같은 날 출장 내역이 여러 건이면 포함한 행 순서로 일비 상한을 적용하므로, 원본 내역과 적용 결과를 함께 확인하세요.

캡처에 없는 식비·숙박비·교통비·기타는 별도 경비 미입력 상태로 기본 `0`이 표시됩니다. 실제 청구할 별도 경비가 있으면 증빙에 따라 입력하세요. 사용자가 금액 칸을 비우면 미확인 값으로 취급하며, `0`은 0원입니다. 확인하지 않은 금액을 0원으로 대신 입력하지 마세요. 청구액을 직접 바꾼 경우 경비 합계와 차이가 생기지 않았는지 확인합니다.

## 검토용과 최종 명세서

다음과 같은 경우에는 확인이 끝난 최종본으로 간주하지 않고 검토용으로 저장합니다.

- 기관 지급기준 또는 OCR 내용·지급대상 확인을 마치지 않은 경우
- 실제 출장시간, 공용차량 등 필수 정보가 누락된 경우
- 포함한 행의 결재상태가 결재완료가 아니거나 금액에 확인할 사항이 있는 경우

노란색 표시는 확인이 필요한 항목입니다. 붉은색 금액·출장기간 오류는 수정한 뒤 저장하세요. 경고가 없는 경우에도 OCR이 내용을 올바르게 읽었다는 보장은 없으므로, 화면의 확인란은 원본 대조를 실제로 마친 뒤 표시합니다.

영수인·대조필의 **서명과 날인은 자동 생성하지 않습니다**. 생성 PDF는 별도로 결재·확인하여 사용해야 합니다.

## 개인정보와 저장 위치

- 이미지 인식과 금액 계산은 이 PC 안에서 처리하며 외부 AI 서비스로 보내지 않습니다.
- 원본 이미지와 입력 내역을 작업 이력이나 로그로 보관하는 기능은 없습니다. OCR 처리를 위해 만든 임시 이미지는 정상 처리 종료 후 삭제합니다.
- 실행 구성요소와 시작 오류 확인용 기록은 로컬 캐시에 남을 수 있습니다. 해당 기록에 원본 이미지나 출장 내역을 출력하지 않습니다.
- 생성 PDF는 브라우저의 다운로드 폴더 또는 사용자가 선택한 위치에 남습니다. 입력 원본과 내려받은 PDF의 보관·삭제는 사용자가 관리합니다.
- 공모전 제출용 화면과 예시 PDF에는 실명, 사번, 소속, 실제 출장 내역 등 개인정보가 포함되지 않도록 가명 자료를 사용하세요.

## 문제가 생기면

| 상황 | 확인할 내용 |
| --- | --- |
| 출장 목록 표를 찾지 못함 | 열 제목과 표 테두리가 모두 보이도록 선명하게 다시 캡처합니다. 지원하는 목록 형식인지 확인합니다. |
| 시간이 틀리거나 비어 있음 | 실제 출발·복귀 시각을 원본과 대조해 수정합니다. 신청시간으로 대신 채우지 않습니다. |
| 금액이 비어 있음 | 관내·동일일 출장인지, 실제 시각과 차량 여부가 입력되어 있는지 확인하고 다시 계산합니다. |
| 명세서 대신 검토용으로 저장됨 | 경고, 필수 정보, 결재상태, 확인란 및 재계산 필요 여부를 확인합니다. |
| 브라우저에서 연결 오류 | 프로그램을 종료한 뒤 실행파일을 다시 열고 새로 열린 화면을 사용합니다. |
| 실행 자체가 차단됨 | 기관의 프로그램 실행 정책을 담당자에게 확인합니다. 보안 설정을 임의로 해제하지 않습니다. |

## 초기 버전의 검증 범위

Windows용 실행파일과 브라우저 화면을 갖춘 초기 구현입니다. 개별 캡처마다 글꼴·해상도·잘린 범위가 달라 OCR 결과를 원본과 확인해야 합니다. Wine에서의 실행·Python/OCR 기능 확인과 실제 Windows 10/11의 브라우저·파일 다운로드 확인은 서로 다른 검증입니다. **실제 Windows PC에서의 전체 사용 흐름은 별도 확인이 필요**하며, 기관 업무에 사용하기 전에 가명 자료로 인식·수정·계산·PDF 저장·종료까지 시험하세요.
