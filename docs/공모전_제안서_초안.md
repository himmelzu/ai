# 아이디어 제안서 초안

**제안명: 출장 화면 한 장으로 만드는 로컬 AI 여비명세서**

소속: __________　성명: __________　직급: __________

## 1. 개선이 필요한 업무 및 문제점

출장처리 시스템에 이미 입력된 내역을 여비지급명세서로 작성할 때, 담당자는 날짜·시간·출장지·목적을 다시 옮기고 차량 사용 여부에 따른 일비와 합계를 계산해야 한다. 같은 정보를 다른 서식으로 옮기는 과정에서 반복 입력과 대조 작업이 발생한다.

특히 신청한 출장시간과 실제 출발·복귀 시각이 함께 표시되어 잘못된 시간을 옮길 수 있고, 미신청·취소·반려 내역이 섞이면 지급대상을 따로 확인해야 한다. 화면 캡처만으로 기존 업무 서식을 만들되, 담당자의 원본 대조와 지급기준 확인을 작업 과정에 포함하는 도구를 제안한다.

## 2. AI 활용 아이디어

**근무지내출장처리 목록의 캡처 → AI 문자 인식 → 담당자 확인 → 여비명세서 PDF 생성** 과정을 하나의 PC용 프로그램으로 연결한다.

신경망 기반의 Tesseract LSTM OCR이 캡처의 한글·숫자를 인식한다. 인식한 글자를 표의 열과 행에 대응시켜 부서·직급·성명·출장일시·출장지·목적·공용차량·결재상태를 정리하고, 담당자가 원본과 비교해 수정할 수 있도록 보여 준다.

업무에 맞춘 핵심 설계는 다음과 같다.

- **실제 시각 구분:** 일비 제안 계산은 실제 출발·복귀 시각을 사용하고, 누락된 값을 신청시간으로 대신 채우지 않는다.
- **지급대상 확인:** 미신청·취소·반려 등으로 인식된 행은 기본 제외하고, 담당자가 포함 대상을 확인한다.
- **확인 후 서식화:** 기관 지급기준과 인식 결과 확인이 끝나지 않으면 검토용 PDF로 표시한다. 서명·날인은 자동 생성하지 않는다.
- **로컬 처리:** Windows 실행파일에 OCR 구성요소를 포함하여 외부 AI 서비스로 출장 자료를 전송하지 않는다.

현재 초기 구현은 PNG·JPG·WebP·BMP 캡처를 읽고, 수정 화면과 관내 일비 제안 계산, A4 가로형 여비지급명세서 PDF 출력을 제공한다. 기준시간·일비·공용차량 차감액·동일인 동일일 상한은 화면에서 확인·조정한다. 초기 제안값인 4시간 이상 2만원, 미만 1만원, 차량 사용 시 1만원 차감, 일일 상한 2만원은 **기관의 현행 기준 확인을 전제로** 하며 관외·여러 날 출장은 별도 검토한다.

AI는 **이미지의 문자를 인식하는 단계**에 사용한다. 표 항목 정리, 여비 계산과 서식 생성은 정해진 규칙을 실행하는 코드이며, AI가 지급 적정성이나 결재를 판단하는 기능은 아니다.

## 3. 업무 처리 방식 비교

| 구분 | 현재(As-Is) | 개선 후(To-Be) |
| --- | --- | --- |
| 처리 절차 | 출장 화면 확인 → 명세서에 재입력 → 실제시간·차량·지급대상 대조 → 계산·서식 정리 | 목록 캡처 → OCR 인식 → 원본 대조·수정 및 지급대상 선택 → 기준 확인·재계산 → PDF 저장 |
| 소요 시간 | 반복 전사와 양식 정리에 시간이 듦. 현재 시간은 실측 필요 | 반복 입력을 줄이고 대조·확인에 집중하는 것이 목표. 절감 시간은 아직 실측하지 않음 |
| 오류·인력 | 시각 혼동, 전사 누락, 합계 오류 등을 담당자가 확인 | OCR 오인식 확인은 여전히 필요하나, 실제시간 구분·미확인 표시·고정규칙 계산으로 확인을 지원 |
| 자료 처리 | 담당자가 원본과 작성 파일을 관리 | 인식·계산을 PC 내부에서 처리하고 원본과 출력 PDF는 담당자가 관리 |

효과는 **같은 가명 출장 10건**을 대상으로 수기 작성과 도구 사용을 각각 수행하여 검증할 계획이다. OCR 처리뿐 아니라 수정·원본 대조까지 포함한 총시간, 일시·차량·금액의 원본 일치 여부, 수정 건수를 비교한다. 아직 측정하지 않은 절감률이나 정확도를 실적으로 제시하지 않는다.

## 4. 기대효과

이미 입력한 출장 정보를 다시 옮기는 작업을 줄이고, 담당자가 실제시간·차량·지급대상과 금액 검토에 집중하도록 돕는다. 기관 양식을 자동으로 구성하여 문서 정리에 드는 수작업을 줄이는 효과를 기대한다.

기존 OCR 기술을 실제·신청시간 구분, 결재상태 확인, 지급기준 확인과 연결한 점이 이 업무에 맞춘 적용이다. 같은 시스템과 양식을 사용하는 부서부터 가명 자료로 시험하고, 다른 양식은 표 구조·지급기준을 별도로 확인한 뒤 확대할 수 있다. 범용 사진 인식이나 여비 지급의 완전 자동화를 주장하지 않는다.

현재는 초기 구현 단계이며 실제 Windows PC에서의 전체 사용 흐름과 담당자 시범 사용을 추가 확인할 예정이다. 공식 업무 적용은 기관의 프로그램 사용 절차, 지급기준, 출력 양식 확인 후 추진한다.
