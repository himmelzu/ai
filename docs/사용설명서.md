# 여비청구서 변환기 v0.3.1 사용설명서

개인별 출장내역 PDF를 넣으면 실제 출장시간과 여비를 정리해 **A4 가로형 여비지급명세서 PDF**로 저장합니다. 변환 결과는 화면에서 확인·수정할 수 있습니다.

## 사용 순서

1. ZIP의 압축을 모두 풀고 `여비청구서 시작.cmd`를 실행합니다. 폴더 안의 실행환경과 파일을 함께 보관하며 시작 파일만 따로 옮기지 않습니다.
2. 열린 화면에서 **PDF 선택**을 눌러 출장내역 파일을 넣거나 입력 영역에 끌어놓습니다.
3. 자동으로 준비된 내역과 합계를 확인합니다. 수정할 내용이 있으면 해당 칸을 바꿉니다.
4. **PDF 저장**을 누릅니다. 브라우저의 다운로드 폴더 또는 선택한 위치에 명세서가 저장됩니다.
5. 작업을 마치면 프로그램 화면의 **종료**를 누릅니다.

실행 중에는 명령창과 브라우저 화면이 함께 열립니다. 작업 중 명령창을 닫지 말고, 종료할 때는 프로그램 화면의 **종료**를 누르세요.

별도 확인란을 표시하거나 재계산 버튼을 누르는 단계는 없습니다. 실제 일시·공용차량·포함 대상 등을 바꾸면 일비가 자동으로 다시 계산됩니다. 지급기준은 접힌 설정에서 조정할 수 있습니다.

## 지원하는 입력

PDF를 한 번에 하나씩, 최대 20MB까지 불러올 수 있습니다.

- **개인별 출장내역 PDF:** 신청·확인으로 나뉜 행을 한 출장으로 묶습니다. 확인행의 실제 출발·복귀 일시를 사용하며 신청시간은 실제 시간으로 대신 넣지 않습니다. 두 페이지 사이에 나뉜 한 쌍도 이어서 읽습니다.
- **18열 출장 월별집계 텍스트 PDF:** 기존 월별집계 형식을 계속 지원합니다.

개인별 내역에 결재상태가 표시되어 있으면 확인행의 상태를 우선합니다. 미전송·취소·반려 등은 기본 청구 대상에서 제외하며 화면에서 해당 내역을 확인할 수 있습니다. 결재상태가 없는 월별집계 형식에는 결재완료 내역만 내보낸 자료라는 업무 규칙을 적용합니다. 상태를 따로 입력하는 절차는 없습니다.

관외·여러 날 출장은 관내 예시 기준으로 자동 계산하지 않으며 기본 제외 상태로 표시됩니다. 필요한 경우 별도 검토 후 포함할 수 있습니다. 같은 PDF에 보여도 청구에 포함할 내역은 화면의 포함 항목으로 구분합니다.

이 프로그램은 지원하는 시스템의 문자·표가 들어 있는 PDF를 대상으로 합니다. 암호가 걸렸거나 다른 양식인 PDF는 읽지 못할 수 있습니다.

## 화면에서 수정할 수 있는 내용

부서·성명·직급·실제 일시·출장지·목적·공용차량·청구 포함 여부와 금액을 확인·수정할 수 있습니다. 원본은 **원본 PDF** 영역을 펼쳐 대조할 수 있습니다.

개인별 PDF에 직급이 없으면 필요할 때 공통 직급 항목에 한 번 입력할 수 있습니다. 원본에 없는 값을 프로그램이 추정해 채우지는 않습니다.

개인별 내역의 지출·여비가 0원이고 세부 경비가 없는 경우, 식비·숙박비·교통비·기타는 기본 0원으로 시작합니다. 별도 경비가 있으면 증빙에 따라 추가합니다. 금액 칸을 비우면 미확인 값으로 취급하며 0원과 구분합니다.

월별집계의 교통비와 현지교통비는 출력 교통비에 합산합니다. 읽지 못한 원본 경비는 0원으로 바꾸지 않고 미확인 상태로 둡니다.

## 지급기준

| 항목 | 초기값 |
| --- | ---: |
| 기준시간 | 240분(4시간) |
| 기준시간 이상 일비 | 20,000원 |
| 기준시간 미만 일비 | 10,000원 |
| 공용차량 사용 시 차감 | 10,000원 |
| 같은 직원·같은 날 일비 상한 | 20,000원 |

초기값은 예시입니다. 소속 기관의 현행 기준에 맞게 설정하세요. 이 프로그램은 모든 감액·지급 제외 사유를 판정하는 법령 검증 기능이 아닙니다.

같은 직원·같은 날 출장 내역이 여러 건이면 포함한 행 순서로 일일 상한을 적용합니다. 일비와 청구액은 화면의 지급기준으로 계산하므로 원본 PDF의 금액과 다를 수 있습니다. 금액을 직접 수정했다면 경비 합계와 청구액도 확인합니다.

## 저장되는 명세서

출력물의 제목은 **여비지급명세서**이며, ‘검토용’·‘검토 중’ 워터마크나 상태 문구는 넣지 않습니다. 확인이 필요한 내용과 제외 사유는 프로그램 화면에 표시합니다.

원본에서 읽지 못한 정보는 추정하지 않습니다. 필수 값이 비어 있으면 해당 칸이 비거나 ‘확인 필요’로 표시될 수 있으므로 필요한 값을 화면에서 수정한 뒤 저장하세요. 서명·날인은 자동 생성하지 않습니다.

## 설치와 개인정보

- Windows 10/11 64비트 PC와 기본 웹브라우저를 사용합니다. Python은 별도로 설치하지 않습니다.
- PDF 추출·금액 계산·명세서 생성은 이 PC 안에서 처리합니다. 원본과 출장 내역을 외부 서버로 보내지 않습니다.
- ZIP에 포함된 Python 실행환경과 프로그램을 그 폴더에서 바로 실행합니다. 실행할 때 내부 실행파일을 새로 풀거나 사용자 캐시에 설치하지 않습니다.
- 원본과 출장 내역을 작업 이력으로 저장하는 기능은 없습니다. 생성한 PDF는 사용자가 선택한 다운로드 위치에 남습니다.
- 시작 오류는 명령창에서 확인할 수 있습니다. 화면의 오류 진단에는 원본 내용·직원 정보·세션 토큰을 넣지 않습니다.
- 제출용 예시 화면이나 PDF에는 실명·사번·소속·실제 출장 내역 대신 가명 자료를 사용하세요.

## 문제가 생기면

| 상황 | 확인할 내용 |
| --- | --- |
| PDF를 읽지 못함 | 시스템에서 내려받은 지원 형식의 PDF인지, 암호가 걸리지 않았는지 확인합니다. |
| 일시가 비어 있음 | 실제 확인행에 시각이 있는지 원본과 대조하고 필요하면 직접 입력합니다. 신청시간을 대신 넣지 않습니다. |
| 금액이 비어 있음 | 실제 일시·차량·출장 구분과 미확인 경비를 확인합니다. |
| 일부 내역이 기본 제외됨 | 미전송 등 원본 상태 또는 관외·여러 날 출장인지 화면의 제외 사유를 확인합니다. |
| 저장 중 오류 | **오류 진단 정보 → 진단 정보 복사**를 눌러 오류 내용을 전달합니다. |
| 연결 오류 | 프로그램을 종료하고 `여비청구서 시작.cmd`를 다시 실행해 새로 열린 화면을 사용합니다. |
| 시작 파일만 복사한 뒤 실행되지 않음 | ZIP 전체를 다시 풀어 시작 파일과 실행환경 폴더를 함께 둡니다. |
| 백신에서 탐지됨 | 실행을 중단하고 격리 상태를 유지합니다. 탐지명·탐지된 파일·백신 이름을 확인합니다. 백신 해제나 예외 등록으로 실행하지 않습니다. |

v0.3.0 단일 EXE는 백신 탐지가 보고됐으므로 격리 상태를 유지하고 실행하지 마세요. 새 ZIP은 별도 폴더에 모두 풀어 사용합니다. 화면에 `v0.3.1`이 표시되는지 확인합니다. 기존 브라우저 탭만 새로고침하면 이전 프로그램 화면일 수 있으므로 새로 열린 화면을 사용합니다.

실제 Windows PC의 기본 브라우저·파일 다운로드는 사용 환경에서 확인하세요. 업무에 적용하기 전 가명 자료로 불러오기·수정·저장·종료 흐름을 시험할 수 있습니다.

v0.3.1은 단일 자체압축 EXE 대신 실행환경과 소스가 보이는 폴더로 배포합니다. 해당 백신이 새 배포 파일을 탐지하지 않는지는 확인하지 못했습니다. 새 배포가 탐지되면 실행을 중단하고, 필요하면 백신 업체의 공식 파일 분석·오탐 신고 절차로 확인하세요.
